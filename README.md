# med-ml-parkinsons-detector

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/BurhanxGodhra/med-ml-parkinsons-detector/blob/main/parkinson_detector.ipynb)

Machine learning classifier for early detection of Parkinson's biomarker patterns.

## Overview
This repository contains a standalone Jupyter/Colab notebook setup for rapid execution and reproducibility.

## Quickstart
1. Click the **Open in Colab** badge above to launch directly in Google Colab.
2. To run locally:
   ```bash
   git clone https://github.com/BurhanxGodhra/med-ml-parkinsons-detector.git
   cd med-ml-parkinsons-detector
   pip install -r requirements.txt
   jupyter notebook parkinson_detector.ipynb
   ```
